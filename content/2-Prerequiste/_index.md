#### Preparation steps

#### Create S3 bucket

In this step, we will navigate to the S3 Console and create an S3 bucket to be used throughout this workshop.

1. Go to: S3 Console [Select here](https://s3.console.aws.amazon.com/s3/home?region=us-east-1)
- Select - **Create Bucket**
- **Bucket Name**: yourname-analytics-workshop-bucket
- **Region**: US EAST (N. Virginia)

![Data Analytics on AWS](/images/1/0001.png?featherlight=false&width=90pc)

2. Leave the rest as default.

![Data Analytics on AWS](/images/1/0002.png?featherlight=false&width=90pc)

3. Optionally add Tags (Label), for example: workshop: AnalyticsOnAWS. Select **Create bucket**

![Data Analytics on AWS](/images/1/0003.png?featherlight=false&width=90pc)

4. Open - yourname-analytics-workshop-bucket (yours)
- Select - **Create folder**

![Data Analytics on AWS](/images/1/0004.png?featherlight=false&width=90pc)

5. The new directory is called: data. Select - **Create folder**

![Data Analytics on AWS](/images/1/0005.png?featherlight=false&width=90pc)

6. Create a folder successfully.

![Data Analytics on AWS](/images/1/0006.png?featherlight=false&width=90pc)

7. Open - data. Select - **Create folder** (From within the data folder)

![Data Analytics on AWS](/images/1/0007.png?featherlight=false&width=90pc)

8. New directory: reference_data. Select **Create folder**

- Open - reference_data

![Data Analytics on AWS](/images/1/0008.png?featherlight=false&width=90pc)


9. Download this file to your machine: [tracks_list.json](https://static.us-east-1.prod.workshops.aws/public/9b2d1982-fdcf-4207-ba26-71a458796115/static/data/tracks_list.json) or [Github](https://raw.githubusercontent.com/AWS-First-Cloud-Journey/Lab-72--Analytics-workshop-on-AWS/master/tracks_list.json)
   - In the S3 Dashboard, select - **Upload**


![Data Analytics on AWS](/images/1/0009.png?featherlight=false&width=90pc)

10. Select **Add files** & **upload** tracks_list.json
   - Select **Upload** (bottom left corner)

![Data Analytics on AWS](/images/1/00010.png?featherlight=false&width=90pc)

11. Download the file successfully.

![Data Analytics on AWS](/images/1/00011.png?featherlight=false&width=90pc)
