#### Run Jupyter Notebook

1. Download and save this file: [https://intro-to-analytics-on-aws.workshop.aws/notebooks/analytics-workshop-redshift-notebook.ipynb](https://intro-to -analytics-on-aws.workshop.aws/notebooks/analytics-workshop-redshift-notebook.ipynb)

  + You can also download the attached notebook file [here](https://000072.awsstudygroup.com/download/analytics-workshop-redshift-notebook.ipynb).

  + Go to: SageMaker Notebook.
  + On the left select **Notebook**.
  + Click **Open**.

![Data Analysis on AWS](/images/10/47.png?featherlight=false&width=90pc)

2. In Sagemaker Jupyter Notebook:
  + Click **Upload** (upper right corner).

![Data Analysis on AWS](/images/10/48.png?featherlight=false&width=90pc)

3. Find and upload **analytics-workshop-redshift-notebook.ipynb** that you downloaded earlier.
  + Click **Upload** to confirm.

![Data Analysis on AWS](/images/10/49.png?featherlight=false&width=90pc)

4. Click **analytics-workshop-redshift-notebook.ipynb** to open the notebook.
  + Make sure '**Sparkmagic (PySpark)**' is in the upper right corner of the notebook, this is the name of the kernel that Jupyter notebook will use to run the notebook's code.

![Data Analysis on AWS](/images/10/50.png?featherlight=false&width=90pc)

5. **Follow the notebook's sequential instructions**.
  + Please take the time to read and understand the step-by-step conversion instructions in the notebook.
