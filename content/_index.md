# Data Analysis On AWS


#### Overview

To get started with Data Analytics on AWS, we will need to learn about the services that can assist us in performing analytics, through this workshop we will get acquainted. with services used in data analytics on AWS such as AWS Glue, Athena, QuickSight, Lambda, Redshift, and EMR.

---
#### Prepare

+ You will need to have an AWS account with **AdministratorAccess** permissions.
+ This lab will be performed in the Singapore partition (**Region: ap-southeast-1**).
+ The best way is to **follow the links of the tutorial** and open them **in a new tab**.
+ Run this lab in popular browsers like Google Chrome, Firefox.
