#### Sign up for QuickSight

1. Go to [Quicksight service admin interface](https://ap-southeast-1.quicksight.aws.amazon.com/en/start).
  + Click **Sign up for QuickSight**.

![Architect](/images/8/1.png?width=90pc)

2. Make sure Enterprise is selected and Click **Continue**.
  + QuickSight account name: ```yournameanalyticsworkshop```.
  + Notification email address: ```you@youremail.com```.
  + Select Amazon Athena - this will allow QuickSight to access the Amazon Athena database.
  Select Amazon S3.
  + Select **yourname-analytics-workshop-bucket**.
  + Click **Finish**.
+ Click **Finish**.
+ Wait a few minutes for the QuickSight account to be created.

![Architect](/images/8/2.png?width=90pc)
