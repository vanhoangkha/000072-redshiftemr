#### Transform data with AWS Glue Studio

AWS Glue Studio is a new visual interface that makes creating, running, and viewing ETL jobs in AWS Glue simpler. You can compose a generic and data transformation process that will run on AWS Glue's Apache Spark ETL serverless engine.

In this section we'll go through the ETL process like we did data transformation with AWS Glue but we'll make use of the graphical interface of AWS Glue Studio!
