#### Chạy Glue Studio job

1. Bắt đầu chạy ETL job bằng cách ấn **Run** ở góc phải màn hình.

![Architect](/images/4/12.png?width=90pc)

+ Bạn sẽ thấy **“Successfully started job”**. 

2. Bạn sẽ thấy PySpark Code của Glue Studio được tạo ra và hãy dùng lại đoạn code này cho mục đích khác, nếu cần.

![Architect](/images/4/13.png?width=90pc)

3. Đi đến Glue DataCatalog: https://console.aws.amazon.com/glue/home?region=ap-southeast-1 và bạn sẽ thấy table **processed-data2** được tạo ra dưới database **analyticsworkshopdb**.
