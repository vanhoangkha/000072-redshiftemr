#### Run Glue Studio job

1. Start running the ETL job by pressing **Run** in the right corner of the screen.

![Data Analysis on AWS](/images/4/18.png?featherlight=false&width=90pc)

+ You will see **“Successfully started job”**.

1. You will see Glue Studio's PySpark Code generated and reuse this code for other purposes, if needed.

![Data Analysis on AWS](/images/4/19.png?featherlight=false&width=90pc)

2. Go to Glue DataCatalog: https://console.aws.amazon.com/glue/home?region=ap-southeast-1 and you will see table **processed-data2** created under database **analyticsworkshopdb **.

![Data Analysis on AWS](/images/4/20.png?featherlight=false&width=90pc)
