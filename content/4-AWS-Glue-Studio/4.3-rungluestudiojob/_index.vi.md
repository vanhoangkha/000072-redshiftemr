#### Chạy Glue Studio job

1. Bắt đầu chạy ETL job bằng cách ấn **Run** ở góc phải màn hình.

![Data Analysis on AWS](/images/4/18.png?featherlight=false&width=90pc)

+ Bạn sẽ thấy **“Successfully started job”**. 

1. Bạn sẽ thấy PySpark Code của Glue Studio được tạo ra và hãy dùng lại đoạn code này cho mục đích khác, nếu cần.

![Data Analysis on AWS](/images/4/19.png?featherlight=false&width=90pc)

2. Đi đến Glue DataCatalog: https://console.aws.amazon.com/glue/home?region=ap-southeast-1 và bạn sẽ thấy table **processed-data2** được tạo ra dưới database **analyticsworkshopdb**.

![Data Analysis on AWS](/images/4/20.png?featherlight=false&width=90pc)
